# Seguridad y privacidad

- El blueprint publicado es una **copia sanitizada**, no el original exportado de Make.
- Se sustituyeron los identificadores de webhook, conexión de Google y documento de Sheets; se eliminaron metadatos de cuentas y nombres personales del prompt.
- Nunca subir: tokens de Telegram, claves API, credenciales, URLs privadas, mensajes reales o registros financieros.
- Los datos usados para ejemplos y pruebas deben ser sintéticos.
- Antes de importar, configurar conexiones nuevas y revisar el prompt y el mapeo en un entorno de prueba.
- Considerar permisos mínimos, acceso restringido al bot, manejo de errores, deduplicación y controles para información financiera.
- Los importes fiscales inferidos por IA deben validarse con reglas deterministas y revisión humana.

El escenario de recordatorios exportado contenía un identificador real de chat de Telegram, identificador de hoja y referencias de conexión. La versión pública los reemplaza por marcadores; antes de importar, configure sus propias conexiones y destinatarios.
